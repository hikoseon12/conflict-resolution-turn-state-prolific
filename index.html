How Is the User Reacting to the AI?

When people chat with an AI assistant, the AI's answer is not always what they wanted. It may be vague or unhelpful, miss the point, push a different plan, disagree with the user's view, or fail to comfort someone who is upset. The user may then push back, complain, or argue. We call this a conflict.

In this task you will read short conversations between a user and an AI assistant. For each item, look at the highlighted user reply and decide how the user is reacting to the AI's previous answer: still going with the conversation, in conflict with the AI, or satisfied.

The highlighted user reply is the one you label:

Conflict definition A conflict does not have to be an open fight. It means the user and the assistant hold two opposing views that still need some resolution. It takes one of four forms:
  • Task-oriented: the user wants a task done and the assistant did not deliver it.
  • Emotional: the user is distressed and still needs to be persuaded or supported.
  • Validation: the user wants agreement with their viewpoint, and the assistant's view differs.
  • Eristic: the user holds an opposing view and wants a debate or a fight.
An ordinary question or request with no opposing view is not a conflict.
